# The Next Yes folder: rules for people and AI assistants

One person's business pipeline and proof, in plain markdown and CSV. Read `README.md` first.

## How to work here
1. Find your task below and read only that file.
2. Load nothing in the Skip column.
3. If this table and the area's `CONTEXT.md` do not say where something lives, stop and ask the owner, then write the answer into the `CONTEXT.md` where it should have been found.
4. Adding new files is fine. Do not edit or move an existing file without the owner's OK, except a routine append they asked for (a ledger row, an evidence-log line).

## Guarded: open only when the owner names the file
- `finances/ledger.csv`
- any `contract.md`, signed PDF, or `invoices/` folder
- the `.backups/` folder: it holds earlier copies of whatever the viewer changed, including the ledger and contracts

Contracts hold legal terms and personal details; the ledger holds all the money.

## Never
- Logins, API keys and client passwords do not go in this folder or in chat.
- Client names, phone numbers and emails do not go into `outputs/` or any public page.
- Assistants draft; the owner sends and publishes every page, listing, quote and ask.
- Personal finances do not belong here. This folder is business money only.

## Public material
Anything made to be seen outside this folder (a portfolio page, a listing, slides, diagrams, pitch text):
- OK to show: names of services, tools and projects.
- Never show: web addresses, hostnames, IP addresses, ports, routes, subdomains or logins, unless the owner has marked that item PUBLIC after checking it, with the date written beside it.
- A client may be named only after they say yes (ASK FIRST).

## Labels on claims
Label every claim twice.
- How you know it (status): `MEASURED` means you counted, timed or signed it. `THEY SAID IT` means someone else said it and it is on record. `PLANNED` means it is an estimate or a goal, so never total plans up as results.
- Who may see it (use): `PUBLIC`, `ANONYMISED`, `ASK FIRST` or `PRIVATE`. Use a claim only for an audience its label allows.
