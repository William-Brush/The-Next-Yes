# Glossary

## Folders and files

| Name | What it is |
|---|---|
| `the-next-yes/` | Everything that lets you say what you do and prove it. |
| `START-HERE.md` | The front page of `the-next-yes/`: the one line, who the next yes is, and where everything lives. |
| `me.md` | You: background, the one sentence, what you want next, what stays private. |
| `work/` | One file per project or client, each with claims labelled by status and use. Where a delivered job turns into proof. |
| `evidence/evidence-log.md` | One row per piece of proof, with an id (e01, e02...) that `work/` records cite. |
| `people/` | Who you have worked with, what they said, and whether you may name them. |
| `opportunities/` | Funders, grants, platform listings, competitions and cold targets. Not people who have talked to you about paid work; those are engagements. |
| `outputs/` | Every pitch, page draft or offer you make, dated and named for its receiver. |
| `finances/` | The tracker: deals, quotes, contracts, hours, invoices, money in. |
| `<payer>/<engagement>/` | One deal. The payer is who signs and pays. Example: `acme/website-refresh/`. |
| `engagement.md` | The deal's index: payer, how it arrived, stage, value, next action, dates, where it stands. |
| `brief.md` | What the client asked for, copied word for word with its source. |
| `quote-v1.md`, `quote-v2.md`... | One file per quote. |
| `contract.md` | The agreement, plus the signed PDF. Guarded. |
| `time.md` | Hours worked on the deal. |
| `invoices/` | Invoices sent. Guarded. |
| `ledger.csv` | One row per money event (invoiced, paid, expense, refund), keyed by engagement id. Guarded. |
| `quote-history.csv` | One trimmed row per past job: type, scope, rate, hours, quoted and signed price, outcome. No contacts or contract terms, but it keeps the engagement id, so it is not anonymous. |
| `rates.md` | Your rate card. Blank until you set it. |
| `templates/` | Blank engagement, brief, quote, invoice, time log, and a contract stub. |
| `quote-skill/` | Instructions for drafting a quote from a brief and your history. |
| `ONBOARDING.md` | The route for a new client or prospect, from first contact to paid. |
| `index.html` | The viewer and editor page. |
| `.backups/` | Hidden. Earlier copies of files the page changed, and a log of each change. Guarded. |

## Concepts

| Term | Meaning |
|---|---|
| Next yes | The one person who agrees to the next step. For you: one person buying one clearly named service. |
| The one line | One sentence: who you help, what changes for them, and how you show it. |
| Engagement | A deal with a named person or company who has talked to you about paid work. |
| Payer | Who signs and pays. An agency is the payer, not the end client behind it. |
| Channel | How a deal arrived: `referral`, `Contra`, `Fiverr`, `agency`, `direct` (your own network), `inbound`. Any other marketplace is named the same way. |
| Stage | Where a deal stands: `lead`, `briefed`, `quoted`, `signed`, `active`, `delivered`, `invoiced`, `paid`, `lost`. Written in `engagement.md`, not shown by folder. |
| Lead vs opportunity | Lead: a named person or company has talked to you about paying for work. Opportunity: grants, funders, competitions, platform listings, cold targets. |
| Warm ask | One ask to one real person who knows your work. Not necessarily a buyer: "will you buy this, or tell me who would?" |
| Status labels | `MEASURED`, `THEY SAID IT`, `PLANNED`: how you know a claim. |
| Use labels | `PUBLIC`, `ANONYMISED`, `ASK FIRST`, `PRIVATE`: who may see it. |
| Guarded | A file an assistant opens only when you name it. |
| Void | A row you mark as cancelled instead of deleting. Void rows stay in the file and are skipped by totals. |
